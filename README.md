## How to work on it
1. Open the repo and press `.` - that opens github.dev in your browser
2. Only edit YOUR files. Don't touch the navbar, footer or style.css - just tell me if something needs changing
3. Open your guide in `guides/` - every step has the code, where to paste it, and a picture of what it should look like. If copying from the PDF acts up, use your `code (copy from here).txt`
4. Ctrl+S, then Source Control (left bar) -> type the message from the guide -> Commit & Push
5. Give it a minute or two then check the live link (Ctrl+Shift+R)

The "Overall Guide" covers the whole project if you need to cover for someone.
